# Review Gate

Before accepting a change:
1. Identify canonical requirements and scope.
2. Inspect actual diff and changed files.
3. Run deterministic tests and Obsidian link audit.
4. Request an independent critical review for architecture, privacy, regressions, risk, and business integrity.
5. Record findings and remediation, identify remaining unknowns.
6. Human approves merges, deployments, outreach, spending or publication.

No claims of passing tests unless test output exists. No reviewer self-approval. For low-stakes research drafts, label unreviewed claims as hypotheses.
