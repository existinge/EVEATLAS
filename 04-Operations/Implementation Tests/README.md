# Implementation Tests

This section holds isolated, reversible implementation and structure experiments. An entry is a trial proposal, not a change to Atlas's canonical roles, routing, budgets, or approval requirements. Check each notice's status before treating anything as connected or deployed.

| Test | Status | Branch |
|---|---|---|
| [DeepSeek Free Review Structure Test](DeepSeek%20Free%20Review%20Structure%20Test.md) | Documented; not configured or run | `experiment/deepseek-free-review` |

Each test should state its reason, current evidence versus hypotheses, scope, handoff format, time and spending limits, success criteria, results, and rollback. Permanent adoption requires a separate decision and scoped change.

## Scholar discovery intake

Scholar investigates useful offers and tools, writes evidence-backed candidates in its own research reports, and hands test proposals to the lead. The Builder owns implementation notices and isolated trials. Outcomes return to Scholar for learning; a proposal does not change production structure.
